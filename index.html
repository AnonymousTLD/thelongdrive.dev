What it is

The Long Drive is a road-trip game about driving and exploring a randomly generated desert, with car maintenance and survival elements.

TLD RevaMP is a mod for the game's beta branch. It has two halves:

  • Making the game run better: 51 fixes reduce work the game repeats, spread out world generation and fix bugs in cars, items and saves. The comparisons below show the measured changes.
  • Playing together: a multiplayer system built from scratch replaces the beta's own multiplayer, sharing players, vehicles, items and world interactions.

It needs your own copy of The Long Drive; the download contains the mod and its loader, not the game. TLD RevaMP is free software under GPL-3.0. About & credits.

Requirements & installation

You need The Long Drive on Steam, its beta branch, and Windows or Linux with Proton (including Steam Deck). BepInEx, the loader that starts the mod, is included in the RevaMP release zip.

  1. In Steam, right-click The Long Drive → Properties → Betas → select beta. Let Steam finish updating.
  2. Close the game and back up Documents\TheLongDrive\Saves before installing or updating.
  3. Open the latest public release. Download the RevaMP zip and follow its INSTALL.txt: extract into the game folder containing TheLongDrive.exe. Steam → right-click the game → Manage → Browse local files opens that folder.
  4. For a manual Linux/Proton install, set Steam → Properties → General → Launch Options to WINEDLLOVERRIDES="winhttp=n,b" %command%.

Using an installer

If the public release includes an installer, you can use it instead of extracting the zip. On Windows, download install.ps1, right-click it and choose Run with PowerShell. On Linux or Steam Deck, download install.sh and run bash install.sh in a terminal (Desktop Mode on Steam Deck). Choose Install or update and follow the prompts. The Linux installer sets the Proton override when the game's Proton prefix exists; otherwise follow its launch-option instructions.

Update, repair or uninstall

To update, close the game and copy the new release zip's files over the old ones, or run the new release's installer and choose Install or update. Everyone playing together needs the same version.

For an installer-managed installation, run the installer again and choose Repair to restore missing or changed files. Uninstall removes the files it installed and restores its backup; settings, logs and reports stay.

For a manual installation, repair by extracting the same release zip again. To remove it, delete winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx folder from the game folder. Keep any reports or settings you want first; removing BepInEx also removes other mods using that loader.

Measurement settings

  • Game: The Long Drive beta (2024.11.26b_test), Unity 2022.3.12f1, BepInEx 5.4.23.5.
  • 1280×720, the game's Ultra preset, vsync off, no frame cap.
  • A separate measuring mod drives the runs and records every frame; it works the same with or without RevaMP. The travel runs follow the main road from the start, and the route was checked to be identical in every run.
  • Frame times are measured on the game's main loop (the processor side, where these fixes work).

Multiplayer, rebuilt from scratch

RevaMP doesn't extend the beta's own multiplayer; it replaces it.

How to host and join

  1. Install the same RevaMP version on every player's game.
  2. One player starts or loads a world, opens Multiplayer (the game's menu button or F11 in game) and chooses Host. A password is optional.
  3. The other players select that Steam friend in their Multiplayer menu and choose Join. Steam relay handles the connection, so this route needs no port forwarding.

The host's machine owns the shared world and save. Joining loads that world and leaves your own saves alone. A version mismatch is refused with an explanation.

What is shared

  • Host and join from the game's own Multiplayer menu (F11 in game). Steam friends see your game; no port forwarding.
  • Play anywhere on the map: each machine simulates what's near its own player.
  • Shared: players (on foot, seated, driving, as passengers), cars (driving, crashes, damage, parts coming off, fuel and fluids), loose items, building doors and gates, creatures, guns, bullet holes and explosions, sandstorms, tumbleweeds and the radio. Players can stand in a moving bus or on a car.
  • Text chat and proximity voice (heard within 60 m).
  • Mod transfer: a player missing a mod the host uses gets it from the host, if it's on RevaMP's approved list.

Bugs in the base game, fixed

  • Cars could vanish from the road when one of their parts was far away.
  • An emptied bottle came back full (30 L) after reloading.
  • Items fell through the world when you arrived faster than it generated.
  • A bus's rear wheels were saved hanging in the air.
  • Lamps in buildings were lost when the building streamed out first.
  • A car's radiator couldn't explode properly; a worn hat could flood the game with errors.
  • Trailers couldn't be hitched at all in the beta.

Brought back and added

  • Rabbits and sandstorms: still in the beta's files, but nothing started them.
  • Trailers that hitch, brake with the car, and don't creep away when parked.
  • Driving assists (all optional): trailer sway reduction, roll correction, traction control.
  • In-game mod browser (Settings → Revamp → Mods): install, update and remove approved mods (next release).
  • One-key bug reports (Page Down): a zip with a screenshot, logs and session timings.

Questions

Does it work on the normal (non-beta) game?

No. The beta is a different version of the game underneath: of the 1,203 parts of the game's code RevaMP uses, 425 don't exist in the normal version, among them the world generator, the save format and the multiplayer layer. RevaMP is built for the beta only.

How do we play together?

One player loads or starts a world and presses Host in the Multiplayer menu (F11, or the game's own Multiplayer button). Steam friends then see the game in their Multiplayer menu and press Join; a password is optional and no port forwarding is needed. Everyone needs exactly the same RevaMP version: the game refuses a mismatch and says why.

What happens to my saves when I join someone?

Nothing. The host's machine owns the world and its save; joining loads the host's world and never touches your own saves.

Which keys does it add?

F11 Multiplayer menu, Page Up performance overlay, Page Down bug report, and the game's Voice chat key (K if it isn't bound) to talk. None of them is a key the game itself uses; they can be changed in BepInEx\config\tldrevamp.core.cfg.

Linux or Steam Deck?

Install it the same way, then set the game's launch options in Steam (Properties → General) to WINEDLLOVERRIDES="winhttp=n,b" %command%.

Something went wrong. What should I send?

Press Page Down right when it happens and once more after playing, then attach the report zip to a RevaMP issue. See Reporting problems for the report folder and what to describe.

How do I remove it?

Use Uninstall if you used the installer, or remove the loader files from a manual installation. See Update, repair or uninstall for the file list.

Reporting problems

Press Page Down when the problem happens. It writes a zip to BepInEx/tldrevamp-feedback/ containing a screenshot, game and mod logs, and recent session timings. Open an issue on RevaMP's GitHub and attach the zip.

Include your game branch and RevaMP version, what you were doing, what you expected and what happened. For multiplayer problems, say whether you were hosting or joining and how to reproduce the problem.
